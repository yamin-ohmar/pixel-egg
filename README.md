# Pixel Egg 🍳

My first pixel-art style small and simple egg cooking simulator made with HTML, CSS, JavaScript, and Canvas.

## How to play

1. Click **Cook egg** to move the whole egg into the pan.
2. Watch the **3, 2, 1** countdown as it cooks.
3. Click **Serve egg** to move the cooked egg onto the plate.
4. Click **Cook egg** again to start a new round.

## How to run

Open `index.html` in a browser. No installation needed.

## What I learned

- Drawing pixel art with Canvas rectangles.
- Organising drawing code into functions.
- Responding to button clicks.
- Tracking the egg's state with variables.
- Using a timer to update the countdown and finish cooking.
- Exploring how CSS controls page layout and button appearance.
